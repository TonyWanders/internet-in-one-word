A program that writes one word for the whole internet to `/output/entry.txt`,
for the make.fun competition
[The Internet in One Word](https://make.fun/bounty/u-ronigrv-the-internet-in-one-word-e388f33b).

Run it with Python 3:

```
python3 main.py
```

It writes the word below to `/output/entry.txt` (or to the path given as
the first argument, or `$OUTPUT_PATH`). No network, no clock, no
randomness. The word is 5 characters, inside the 1 to 30 gate, a single
word and nothing else.

## The word

```
feral
```

Why this word: the internet is untamed. No leash, no owner, no manners.
It bites, it strays, it feeds itself, and nobody is really in charge of
it. One word, funny on its own, true of the whole internet rather than
one app, and not the first obvious word anyone reaches for.
